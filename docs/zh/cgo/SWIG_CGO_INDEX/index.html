    GoVector SWIG CGO 集成 - 完整文档索引¶

    📚 文档概览¶

    本文档系列详细说明了如何使用 SWIG 为 GoVector 向量数据库项目创建 CGO 兼容接口，使 Python、C++、Java 等多种编程语言能够调用 GoVector 的核心功能。

    📖 文档列表¶

    1. SWIGINTEGRATIONGUIDE.md - 集成指南（第一部分）¶

    内容概要： - ✅ SWIG 简介和优势 - ✅ 环境准备和安装 - ✅ 项目结构改造 - ✅ SWIG 接口文件编写 - ✅ C 头文件定义（完整 API 声明）

    适合人群：初学者，想要了解整体架构的开发者

    阅读建议：从头到尾阅读，理解整体设计思路

    2. SWIG_IMPLEMENTATION.md - 实现细节（第二部分）¶

    内容概要： - ✅ Go 导出函数完整实现 - ✅ 类型转换和数据映射 - ✅ 内存管理策略 - ✅ 构建配置（Makefile、build.sh） - ✅ 全局资源管理和并发控制

    适合人群：实现开发者，需要深入理解 CGO 机制

    阅读建议：结合代码阅读，理解每个函数的实现细节

    3. SWIGEXAMPLESANDBESTPRACTICES.md - 示例与最佳实践（第三部分）¶

    内容概要： - ✅ Python 使用示例（简单示例 + 封装类） - ✅ C++ 使用示例 - ✅ Java 使用示例 - ✅ 内存管理最佳实践 - ✅ 错误处理模式 - ✅ 并发安全控制 - ✅ 性能优化技巧 - ✅ 调试技巧 - ✅ 测试策略 - ✅ 发布与分发

    适合人群：所有开发者，特别是需要实际编写代码的开发者

    阅读建议：重点阅读示例部分，参考最佳实践编写代码

    4. SWIGQUICKREFERENCE.md - 快速参考卡片¶

    内容概要： - ✅ 快速开始指南 - ✅ API 函数速查表 - ✅ 常见错误及解决方案 - ✅ 性能优化技巧 - ✅ 调试命令 - ✅ 最佳实践清单

    ⚠️ 常见陷阱¶

    1. 内存泄漏¶

    # ✗ 错误
results = client.search(query)
# 忘记释放 results

# ✓ 正确
results = client.search(query)
# 使用后立即释放

    2. 错误处理¶

    # ✗ 错误
storage = govector_storage_new(path, None)
# 不检查返回值

# ✓ 正确
error = govector.ErrorInfo()
storage = govector_storage_new(path, error)
if not storage:
    print(f"Error: {error.message}")

    3. 并发安全¶

    # ✗ 错误：多线程共享句柄
thread1: client.search(...)
thread2: client.search(...)  # 可能冲突

# ✓ 正确：使用锁保护
with lock:
    client.search(...)

    调用方式性能¶

    CGO 单次调用 10x 0.1x 低频操作

    🎯 最佳实践总结¶

    ✅ 必做清单¶

    1. 总是检查错误返回值
    2. 及时释放所有资源
    3. 使用批量操作减少 CGO 调用
    4. 在多线程环境中使用锁
    5. 使用工具检测内存泄漏

    ❌ 禁止清单¶

    1. 不要忽略错误
    2. 不要忘记释放 C 内存
    3. 不要频繁进行 CGO 调用
    4. 不要共享未保护的句柄
    5. 不要传递 Go 指针给 C 长期保存
