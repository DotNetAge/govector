    Vector Database Getting Started Guide¶

    Welcome to the Vector Database Getting Started Guide! This documentation series is designed to help readers with zero foundation systematically understand the core concepts, application value, and learning paths of vector databases.

    Documentation Structure¶

    This guide uses a modular design with content progressing from basics to advanced topics, divided into the following chapters:

    vectordb/
├── README.md                    # This file - Documentation navigation
├── 01-introduction.md          # Chapter 1: Introduction
├── 02-history.md               # Chapter 2: Development History
├── 03-core-principles.md       # Chapter 3: Core Principles
├── 04-basic-concepts.md        # Chapter 4: Basic Concepts
├── 05-applications.md          # Chapter 5: Application Scenarios
└── 06-learning-path.md         # Chapter 6: Learning Path

    Suggested Learning Path¶

    It is recommended to read each chapter in order:

    Order Chapter Description Estimated Reading Time
    1 Introduction Learn what vector databases are and why we need them 10 minutes
    2 Development History Learn about the technological evolution of vector databases 8 minutes
    3 Core Principles Deep understanding of vector representations and index mechanisms 15 minutes
    4 Basic Concepts Master core terminology like embedding, dimension, similarity 12 minutes
    5 Application Scenarios Learn about practical applications of vector databases 10 minutes
    6 Learning Path Get resources for continued deeper learning 5 minutes

    Quick Navigation¶

    If you're short on time...¶

    Only want to understand the core concepts? Recommended reading: 1. Introduction - What is a Vector Database 2. Core Principles - Vector Representation 3. Application Scenarios

    If you want to dive deeper...¶

    Recommended to read all chapters, especially: - Core Principles - Understand index structures and distance calculations - Basic Concepts - Master terminology
